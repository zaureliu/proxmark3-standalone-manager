# Screenshots

No screenshot is stored in this folder.

A capture of the live window would show the COM port, the MCU line, the SPI
flash size, the Standalone banner last read from the device, and the local
ProxSpace path. Those details identify this machine and this board. They
are not needed to explain the program, and they must not be published.

A drawn or generated picture of the window would not be the real interface.
It is not included.
